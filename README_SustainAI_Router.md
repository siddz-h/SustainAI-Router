## Claim guardrails

- No claim that SustainAI Router invented model routing.
- No claim that existing routing systems ignore sustainability completely.
- No universal energy, carbon or water figure.
- No exact environmental savings percentage.
- No fake evaluation results.
- Relative resource labels are conceptual assumptions until calibrated with measured data.

## Prototype limitations

The HTML demo uses a transparent deterministic mock classifier so that it works offline and does not retain prompts. In a future no-code build, replace that step with a structured LLM classification prompt, a Google Sheets/Airtable model registry and Make/Zapier/Glide automation. Keep the same disclosures and quality/fairness safeguards.
